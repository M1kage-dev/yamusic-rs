# Изменения

Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/). Номер версии — своя линия,
база апстрима в метаданных `+upstream.A.B.C` (см. раздел «Версии» в README). Раздел для
текущего тега попадает в описание релиза; если раздела нет, сборка релиза падает.

## [1.0.9+upstream.1.1.7] — 2026-11-25

- Из [апстрима 1.1.7](https://github.com/SpolzerMod/yamusic-rs/releases/tag/v1.1.7): горячие клавиши как в официальном приложении, полоса прокрутки на страницах и клавиши PgUp/PgDn, Home/End.
- «Новые релизы» показывают все релизы с обложками; альбомы исполнителя идут от новых к старым, как в оригинале. В «Моей волне» можно повторять трек, а восстановленная волна подписана своим названием.
- Исправлено в Ynison: позиция восстановленного трека при выходе во время загрузки, выбранный трек из смешанной очереди, дочитывание декодированного файла перед перемоткой.
- Подменю языка и темы в профиле видно в тёмной теме; надпись формата в плеере стоит по центру кнопок.

## [1.0.8+upstream.1.1.6] — 2026-11-24

- Из [апстрима 1.1.6](https://github.com/SpolzerMod/yamusic-rs/releases/tag/v1.1.6): кроссфейд между треками, продолжение воспроизведения с сохранённой позиции (синхронизация через Ynison) и докачка трека после обрыва соединения.
- В «Моей волне» можно выбрать характер, настроение и язык. Плеер показывает формат звука; поиск открывает выдачу по трекам.
- Форк теперь публикует только `.dmg` для Apple Silicon и Intel. Windows и Linux x86-64 остаются в CI для тестов и Clippy, но не блокируют релиз macOS.
- **Переход для Windows и Linux:** если раньше пользовались сборками форка, вручную установите [версию апстрима](https://github.com/SpolzerMod/yamusic-rs/releases/latest). Старый обновлятор ищет релизы здесь и сам источник не сменит. Подписанный Android APK, как и прежде, выпускает апстрим.

## [1.0.7+upstream.1.1.5] — 2026-11-22

### Добавлено

- Скачивание альбомов и плейлистов из меню «⋯», выбор логарифмической шкалы громкости.
- Пакеты Linux ARM64 (`.deb`, `.rpm`, AppImage) в дополнение к Linux x86-64,
  Windows и универсальному `.dmg` для macOS.
- Из [апстрима 1.1.5](https://github.com/SpolzerMod/yamusic-rs/releases/tag/v1.1.5)
  синхронизированы и исходники Android. Подписанный APK выпускается в апстриме, не в этом форке.

### Изменено

- Аудио декодируется наперёд в отдельном потоке. Данные трека докачиваются во временный
  файл, а не хранятся целиком в памяти. Если звуковой выход завис во время воспроизведения,
  плеер пытается открыть его заново.
- Альбомы исполнителя показаны от новых к старым, «Знакомое вам» открывает список треков.
  Шрифты и значки догружаются в фоне, если не скачались при запуске.
- Поддержка SOCKS5 через `ALL_PROXY` без подключения системного прокси macOS.

## [1.0.6+upstream.1.1.4] — 2026-11-21

### Изменено

- Вобран апстрим **1.1.4**: скачивание в FLAC, если у трека есть lossless; новая страница
  «История» — что слушали по дням; окно запоминает место и размер между запусками; «Выйти»
  отзывает токен на сервере, а не только стирает локально; вход просит у Яндекса права только
  на Музыку; код входа показывается строчными, как его выдаёт Яндекс.
- Отдельно для macOS: в мини-плеере сохранили нашу обработку нативного полноэкранного режима
  (запоминать экранную геометрию нельзя) поверх новой логики апстрима с `places`.

### Проверено

- После мержа: `cargo test` (46 тестов), `clippy --all-targets -D warnings` — чисто.

## [1.0.5+upstream.1.1.3] — 2026-11-20

### Изменено

- Токены на macOS больше не лежат в «Связке ключей». ACL записи привязан к конкретной сборке,
  поэтому macOS заново спрашивала доступ после каждого обновления: ни ad-hoc подпись, ни
  собственный сертификат с постоянным designated requirement этого не меняют. Теперь токены
  в файле `secrets.json` рядом с настройками, права `0600` — читает только владелец, диалогов
  нет. После этого обновления нужно один раз войти заново.
- Убрана зависимость `security-framework` — приложение больше не обращается к связке ключей.

## [1.0.4+upstream.1.1.3] — 2026-11-20

### Изменено

- Вобран апстрим **1.1.3**. Плеер переписан на потоковое воспроизведение (`src/stream.rs`):
  трек начинает играть, пока докачивается. «Моя волна» учится на прослушиваниях и отправляет
  пропуски ещё до загрузки трека. Фильтр 18+ соблюдается при повторе списка и возврате назад,
  а трек удаляется по позиции из актуальной ревизии плейлиста (а не по устаревшей копии).

### Проверено

- После мержа: `cargo test` (40 тестов), `clippy --all-targets -D warnings`, универсальный
  бандл `x86_64 arm64`, подпись `Yandex Music RS` — на macOS всё собирается и запускается.

## [1.0.3+upstream.1.1.2] — 2026-11-20

### Изменено

- Токены лежат в «Связке ключей» одной записью `tokens` вместо двух отдельных: доступ
  запрашивается к записи, а не к каждому токену, поэтому диалогов вдвое меньше.
- Сборка подписывается собственным сертификатом `Yandex Music RS` вместо ad-hoc: личность
  приложения постоянна (`identifier + certificate root`). На запросы доступа к связке ключей
  это, как выяснилось позже, не влияет — см. 1.0.5, где токены переехали в файл `0600`.

## [1.0.2+upstream.1.1.2] — 2026-11-20

### Исправлено

- Версия в интерфейсе и в системном «О программе» показывалась вместе с метаданными, а в

## [1.0.1+upstream.1.1.2] — 2026-11-20

### Добавлено

- Значок в строке меню macOS (`NSStatusItem`): показать или скрыть окно, играть/пауза,
  предыдущий и следующий трек, выход.
- Универсальная сборка `.app` (arm64 + x86_64) и `.dmg` с ярлыком Applications:
  `tools/macos-app.sh --universal --dmg`.
- Сборка macOS в GitHub Actions: clippy, тесты, проверка подписи и `lipo -archs`, `.dmg`
  в артефактах и в релизе по тегу.
- Автообновление на macOS: приложение скачивает `.dmg`, сверяет SHA-256, монтирует образ,
  проверяет подпись нового бандла и подменяет `.app` после выхода.

### Исправлено

- Запросы больше не идут через системный прокси: приложение не зависит от Proxyman и других
  отладчиков. С этой фичей связь пропадала, как только прокси выключали.
- Если связка ключей macOS отказала, токен больше не сохраняется в `config.json` открытым текстом.
- Мини-плеер встаёт по видимой области экрана (`NSScreen.visibleFrame`), а не уезжает под Dock.
- Выход из нативного полноэкранного режима не запоминает экранную геометрию окна.
- Обложка для «Исполняется» качается общим HTTP-клиентом, без нового потока на каждый трек.

### Изменено

- Схема версий: своя линия `X.Y.Z` плюс `+upstream.A.B.C`; обновлятор сравнивает только
  числовую часть, поэтому каждый релиз поднимает номер.
- `README.md` переписан под форк: что добавлено, состояние проверки, ограничения, версии.
